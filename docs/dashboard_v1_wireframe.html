DV · TUG  /  Wireframe V1 — mockup navegável

Este arquivo é o mockup visual do dashboard V1 especificado em dashboard_v1_spec.md / .html, já com o refinamento de uxers_guidance.md aplicado — estrutura N–J (N é a região nova), renderizada como um export plausível em vez de um esquema de caixas. Cada região carrega 1 princípio primário + no máximo 1-2 secundários, etiquetados por bloco (Fundamentos de Design / Experiência do Usuário / Acessibilidade) no diagnóstico abaixo. Os números de cabeçalho (os 8 KPIs, a divisão por sexo, as médias anuais de ocupação, os 848.764 internações de Porto Alegre, a cauda etária 97–99) são reais, conferidos contra a base. O preenchimento fino — os valores mês a mês da série e do tabelão, os nomes das ~50 especialidades de cauda longa, os pontos da dispersão — é sintético, gerado só para dar volume visual ao mockup; está sinalizado onde aparece. RS · 2019–2023 SIH-SUS × CNES Layout fixo 1200 px

Ative "Mostrar diagnóstico" no topo — cada região A–J ganha um contorno tracejado e um selo; passe o mouse (ou o foco do teclado) sobre uma delas para ver, no rodapé, qual princípio ela viola e qual é a virada na V2.
